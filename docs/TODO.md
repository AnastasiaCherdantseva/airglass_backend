Фильтры для GET /users:

по ролям (role_ids), с режимами «только выбранные» / «включает роль»;

по поддереву от произвольного parent_id, не только от актора;

с промежуточными узлами — если у ребёнка совпал фильтр, показывать его родителя, даже если родитель не совпал;

пагинация на каждом уровне (своих 10, вложенных 5).
